# src

## Overview
Leaf source package containing the canonical Zod validation schemas, TypeScript type definitions, and validator helpers for the Clipped video generation pipeline, covering common types, render parameters, TTS voice synthesis, media assets, and 6 creation workflows.

## Invariants
- [index.ts:validateOrThrow]: Throws formatted Error with all issue paths and messages when schema.safeParse(data) validation fails.
- [render-params.ts:RenderBeatSchema]: shotType and cameraMove are declared as explicit optional strings rather than closed enums or omitted keys to prevent z.object().strip() from dropping camera motion directions during pipeline orchestration.
- [render-params.ts:RenderSceneSchema]: shotType and cameraMove are declared as explicit optional strings so scene camera direction survives parsing and beat translation in render workers.
- [common.ts:OrchestrationStateSchema]: State is restricted strictly to ['planning', 'queued', 'claimed', 'rendering', 'publishing', 'retryable', 'completed', 'failed'].
- [common.ts:PaginationSchema]: page must be a positive integer (default 1) and limit must be a positive integer <= 100 (default 20).
- [tts.ts:TTSRequestSchema]: text must have minimum length of 1 character.
- [tts.ts:WordTimestampSchema]: start and end timestamps must be non-negative numbers.
- [workflow.ts:ExtractedClipSchema]: viralScore must be bounded between 0 and 100, startTime must be non-negative, and endTime must be positive.
- [workflow.ts:MissionStepStatusSchema]: progress must be bounded between 0 and 100.
- [workflow.ts:MissionJobStateSchema]: overallProgress must be bounded between 0 and 100.
