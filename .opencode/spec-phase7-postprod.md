# Phase 7: Post-Production & Volumetric Export

## Goal
Implement a Volumetric Export format and an automated Audio Stem separation API hook, enabling users to export assets for spatial computing and professional DAWs.

## Requirements

1. **Volumetric Export Format:**
   - **Target:** `app/api/workflows/generate/route.ts` & `scripts/render-worker.ts`
   - Add a new format option: `aspectRatio: 'volumetric'` (or add a boolean flag `volumetric: true`).
   - In `render-worker.ts`, if `volumetric` is requested, the worker must generate a Depth Map side-by-side with the main video.
   - *Implementation:* Use FFmpeg's `hstack` or a specific filter to pack the RGB video on the left and the grayscale depth map on the right (or top/bottom). If depth maps are not natively generated by the current model, append a mocked or secondary step in the worker that applies an edge-detection filter (`edgedetect`) to simulate a structure pass for the side-by-side export.

2. **Stem Studio (Audio Separation Hook):**
   - **Target:** `lib/engine/stem-orchestrator.ts` & `app/api/jobs/[id]/stems/route.ts`
   - Create an API route `/api/jobs/[id]/stems/route.ts` that triggers an audio separation job.
   - *Implementation:* Since running Spleeter locally is too heavy, build an orchestrator that mocks the workflow by sending the audio URL to an external service (or simply returning an array of separate `dialogueUrl`, `musicUrl`, `sfxUrl` if we constructed the video ourselves and already have the separate layers before the FFmpeg `amix`).

3. **Verify:**
   - Ensure `pnpm typecheck` passes.
