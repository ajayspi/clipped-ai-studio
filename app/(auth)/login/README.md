# login

## Overview
Client page component for user login rendering AuthForm in 'login' mode.

## Interface
- [page.tsx:LoginPage] Default export React component rendering <AuthForm mode="login" />

## Invariants
- [page.tsx:use client] Marked with 'use client' directive for client-side rendering
- [page.tsx:LoginPage] Statically configured with mode="login"

## Side Effects
- None

## Verification
