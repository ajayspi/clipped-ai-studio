# register

## Overview
Client page component for user registration rendering AuthForm in 'register' mode.

## Interface
- [page.tsx:RegisterPage] Default export React component rendering <AuthForm mode="register" />

## Invariants
- [page.tsx:use client] Marked with 'use client' directive for client-side rendering
- [page.tsx:RegisterPage] Statically configured with mode="register"

## Side Effects
- None

## Verification
- Run: `pnpm test`
