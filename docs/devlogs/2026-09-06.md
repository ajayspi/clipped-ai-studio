## 2. Key Architecture & Code Changes

1. **Voice Reliability Engineering Plan (`2026-09-06-tts-voice-render-reliability.md`)**:
   - **Problem Diagnosis**:
     * Edge TTS WebSocket connections intermittently dropped or hung indefinitely under high concurrency.
     * Render workers failed to decode `data:` base64 URIs, attempting to call `fetch()` on data strings.
     * Remotion composition lacked `<Audio />` components, causing silent video previews.
     * Concatenated FFmpeg clips lacked an audio track when one scene missed sound, leading to mute renders.
   - **Architectural Solution**:
     * 3-tier synthesis cascade: Edge TTS (with 5000ms timeout guard) -> Google Translate TTS REST -> In-memory synthetic 24kHz PCM WAV generator.
     * Direct binary base64 decode in `scripts/render-worker.ts`.
     * Explicit FFmpeg audio mapping (`-c:a aac -b:a 192k` with `anullsrc` padding).

2. **Fal.ai Media Queue Pipeline Plan (`2026-09-06-fal-image-video-pipeline.md`)**:
   - Outlined `lib/engine/image-orchestrator.ts` and `lib/engine/image-sourcer.ts`.
   - Polling queue abstraction for Fal.ai Flux/SDXL models.
   - Graceful fallback hierarchy: User Stock Media -> Pexels/Pixabay -> Openverse (Keyless) -> Pollinations AI.
