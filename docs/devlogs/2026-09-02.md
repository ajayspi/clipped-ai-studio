## 2. Key Architecture & Code Changes

1. **Smart API Router & Auto-Failover Engine (`lib/api-router.ts`)**:
   - Designed a dynamic health-checking router that pings upstream endpoints and caches availability status.
   - Built a priority failover cascade: Paid/Configured Keys -> Free Keyless Fallbacks (Pollinations, OpenRouter Free, Edge TTS, Google Translate REST).
   - If an API returns a 429 quota error or network timeout, the router automatically drops to the next tier without interrupting video generation.

2. **45+ Provider Registry Architecture**:
   - Expanded the provider catalog across LLMs, Image Generation, Video Generation, TTS, Stock Media, and Music.
   - Added zero-cost providers: Pollinations (SDXL/Flux), Openverse, Mixkit, Microsoft Edge Neural TTS.

3. **Dynamic Supabase Connection & Cookie Sync**:
   - Implemented a custom Supabase connector in the UI allowing users to input their own Supabase URL and Anon Key.
   - Persisted connection strings in LocalStorage and HTTP cookies with SSR synchronization.

4. **Modern Subtitles Engine Redesign**:
   - Specified 6 distinct visual subtitle presets:
     * *Hormozi Pop* (high-contrast yellow/black spring pop).
     * *Cyber Neon* (neon cyan/magenta glow shadows).
     * *Minimalist Clean* (clean white Sans-Serif with subtle drop shadow).
     * *Cinematic Boxed* (frosted glass semi-transparent black pill box).
     * *Bold Impact* (all-caps heavy font with thick black outline).
     * *Retro Karaoke* (color-changing highlight on spoken words).
   - Integrated word-level timestamps and 3-zone smartphone vertical positioning.

5. **Visual Workflow Cover Images**:
