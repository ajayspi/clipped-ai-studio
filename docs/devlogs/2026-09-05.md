## 2. Key Architecture & Code Changes

1. **Single Gateway Settings Panel (`app/(app)/settings/page.tsx`, `app/api/settings/keys/route.ts`)**:
   - Replaced multi-category provider tabs with a streamlined OmniRoute Gateway configuration card.
   - Requires only two core inputs: **OmniRoute Endpoint URL** (defaulting to `http://localhost:20128/v1`) and **API Key**.
   - Preserves underlying database compatibility while simplifying user onboarding.

2. **Unified Key Resolution Chain (`lib/keys.ts`)**:
   - Built `getOmniRouteConfig()` implementing a 3-tier precedence chain:
     1. Live Supabase `settings` table record.
     2. Environment variables (`process.env.OMNIROUTE_ENDPOINT`, `process.env.OMNIROUTE_API_KEY`).
     3. Local fallback default: `http://localhost:20128/v1` with keyless access.

3. **Core Engine Refactor (`lib/engine/llm.ts`, `lib/engine/tts.ts`)**:
   - `lib/engine/llm.ts`: Refactored to target OmniRoute using the smart model selector `'auto'`. Standardized OpenAI SDK client instantiation.
   - `lib/engine/tts.ts`: Simplified TTS routing: Attempt OmniRoute speech synthesis first, falling back to Microsoft Edge Neural TTS and Google Translate REST.
   - Updated all workflow orchestrators (`auto-pilot`, `bulk-planner`, `drama-orchestrator`, `scene-matcher`, `shorts-extractor`, `stories-orchestrator`, `whiteboard-orchestrator`) to consume `getOmniRouteConfig()`.

4. **Remotion Composition Rebuild (`remotion/Composition.tsx`)**:
   - Reconstructed `MainComposition` from scratch using `@remotion/player`.
   - Added beats timeline support, smooth cross-fading, dynamic subtitle overlay positioning, and video/image asset sequencing.

5. **Distributed Render Job Lease Locking (`supabase/migrations/20260905_render_job_leases.sql`)**:
   - Implemented distributed locking columns on `render_jobs`:
     * `lease_holder`: Identifier of the worker claiming the job.
     * `lease_expires_at`: Timestamp after which another worker can reclaim a stalled job.
   - Created PostgreSQL function `claim_render_job()` for safe, race-free background execution across multiple worker threads.
