## 2. Key Architecture & Code Changes

1. **Zustand State Isolation Bug Fix (`components/wizard/wizard-store.ts`)**:
   - **Problem**: `platforms` was declared twice in the initial store state. One referred to media stock providers (Pexels, Pixabay), while the other was intended for social distribution targets (YouTube, TikTok). Selecting one caused the other to disappear or cause layout glitching.
   - **Fix**: Isolated the state keys into `platforms` (media sourcing) and `publishingPlatforms` (social distribution).

2. **Full Dynamic Video Library (`app/(app)/library/page.tsx`)**:
   - Replaced placeholder mock data with live Supabase client queries.
   - Wired real video card hydration, render status indicators, filter tags, and inline video player previews.

3. **Background Worker Race Condition Fix (`scripts/render-worker.ts`)**:
   - Resolved a race condition where the rendering worker attempted to generate MP4 video before the AI script generation was fully committed to the database.
   - Implemented state checking ensuring `payload.beats` exists before Remotion bundling starts.

4. **Oracle VM Deployment Safety Rules (`.agents/rules/oracle-deployment.md`)**:
   - Established strict deployment rules: Never build Docker on the Oracle VM (952MB RAM limitation causes OOM hangs).
   - Local builds (`npm run build`) followed by zipped SCP transfer.
   - Patched `zip_fast.py` to prevent recursive zip bomb crashes by explicitly skipping files ending in `.zip`.

5. **Landing Page & Remotion Fixes**:
   - Enhanced landing page with live AI performance metrics (`d166b47`).
   - Fixed missing `registerRoot` in `remotion/Root.tsx` (`1abd845`).
   - Standardized PM2 process configuration in `ecosystem.config.js` (`88aa033`).
