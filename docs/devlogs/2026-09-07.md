## 2. Key Architecture & Code Changes

1. **Edge TTS Voice Catalog Resolution (`lib/engine/tts.ts`)**:
   - Implemented `resolveKeylessVoice()` to reliably map catalog IDs (`free-en-us`, `free-en-in`, `free-hi-in`, `free-ta-in`, `free-te-in`, `free-kn-in`, `free-bn-in`, `free-mr-in`) to verified Microsoft Edge Neural voices.
   - Eliminated the previous bug where non-US requests collapsed to standard US male/female voices.

2. **Three-Tier Fallback Cascade with Timeout Guards (`lib/engine/tts.ts`)**:
   - **Tier 1: Microsoft Edge Neural TTS**: Wrapped in a 5000ms `Promise.race` timeout guard to prevent infinite WebSocket hangs during connection stalls.
   - **Tier 2: Google Translate TTS REST**: Sentence-chunked (<=180 chars) HTTP fallback with automatic punctuation splitting.
   - **Tier 3: In-Memory Synthetic PCM WAV**: Deterministic 24kHz mono WAV audio synthesis ensuring voice requests *never* throw or yield empty audio.

3. **Render Worker Base64 Decoding & FFmpeg Audio Muxing (`scripts/render-worker.ts`)**:
   - `downloadFile()` intercepts `data:` URIs and directly writes binary base64 decoded buffers to disk, preventing Node.js `fetch()` exceptions.
   - Configured FFmpeg with explicit audio stream mappings (`-map 0:v:0`, `-map 1:a:0`, `-c:a aac -b:a 192k`).
   - Integrated `anullsrc=r=44100:cl=stereo` fallback filter to prevent concatenation crashes when individual scenes lack an audio track.

4. **Remotion Live Audio Player (`remotion/Composition.tsx`)**:
   - Imported `Audio` from `'remotion'` and rendered `<Audio src={beat.audioUrl} />` for all beats.
   - Enabled full audio playback in the live browser composition preview.
